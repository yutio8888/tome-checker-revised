# 怪物棋子化首批制作规范

本轮目标：在已有森林／水域棋盘上制作五个可独立使用的怪物母版，验证“同一套桌游棋件”能否同时区分二足、四足、盘曲和放射轮廓。不是全游戏怪物完成版，不含换装。

## 稳定的视觉语言

- 形象：手绘上色的小型雕刻棋件，轮廓概括、体积明确，有少量干刷高光。延续原型的高角度俯视，能看见脸和背；不是平视头像，也不是纯正顶视的背部照片。
- 结构：单个完整生物，放在统一的中性深灰褐圆形薄底盘上。主体和盘内接触阴影可以绘在同一 PNG；底盘外必须是真透明。盘面无碎石、草丛和场景装饰。
- 光线：左上软光、右下短暗部；哑光材质，不用发光眼睛或大面积高亮金属。
- 比例：方形母版建议 1024×1024；圆盘占画布约 86%，居中、近圆形，不是窄椭圆。主体占盘径 75–88%，五官和种族特征略夸张。全部轮廓留在盘内，不能伸进邻格。
- 色彩：低至中饱和的自然色，主体比底盘亮；暖骨色点亮牙爪／口鼻，避免全身绿色贴近草地。不能把阵营色画入外圈。
- 小尺寸优先：实际使用 64px，48px 是压力检查，96px 是放大检查。48px 下先认轮廓，64px 下再认物种和主要特征；毛发／鳞片不得成为唯一识别依据。

## 动态标记和映射

生物画作不包含阵营、rank、选中、状态、血量、召唤或文字信息。程序独立绘制这些标记；同一张狼图可用于敌对、友好或中立实例。现有原生血条／目标提示继续承担规则信息，新增圈色必须读取实时阵营关系，不能按物种猜测。

首批只映射上述五个具体图像／实体，不能用 troll/canine/bear/snake/plants 的 subtype 全覆盖。普通亚种要保留体型、头部、姿态和配色差异；Prox、Bill 等独特者先用原图，后做专属棋子。

## 生成与验收流程

1. ImageGen 先生成森林巨魔作为共同风格样张；查看原始 PNG、透明边界与尺寸后，其他怪物用同一样张作风格参考。每个怪物单独调用、单独 PNG。
2. 生成源图、完整 prompt、参考图路径及原始返回路径写入本目录；不得只留在生成缓存目录。
3. 本轮先按 48／64／96px 检查种类轮廓、主体与底盘对比、透明边缘、盘径和光线。必要时只对失败项用 ImageGen 返修，不用程序补画生物。
4. 导出只做机械尺寸归一化／格式转换；不以抠底、重着色或拼造生物掩盖生成缺陷。程序层圆圈、rank 标记是明确的独立 UI 图形。
5. 产物区分为生成母版、可接入候选、实机验证通过；静态可辨识是内部判断，不能代替真实战斗、密集同种和玩家测试。

## 后续制作顺序

- 第 1 批：本轮五种形体与动态阵营分离。
- 第 2 批：巨魔沼泽实际亚种、鼠／虫／蜂群与独特巨魔；泛滥布局水生怪单列。
- 第 3 批：骨骼／幽灵、蛛虫、类人施法者、构装体等不同材质和语义族群；先解决普通／稀有／独特的相互区分。
- 第 4 批：其他地区和 DLC 缺口。按实体映射及独特轮廓验收，不以 PNG 总数充当设计数量。

具体源文件数量、首批映射及可核实的分组见 inventory/。发布前仍需整合运行时映射、变身／幻象、隐身和阵营变化的显示契约。
