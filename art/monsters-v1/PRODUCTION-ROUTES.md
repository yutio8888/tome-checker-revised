# AI 直出与 Blender 建模后渲染

2026-09-26，针对本项目当前的单视角、48–96px 怪物棋子。以下是制作判断，不是已经完成的两路线成本基准测试。

用户后续决定：**暂不进行 Blender 实验，继续 AI 直出并扩充怪物种类。** 下述对照方法仅保留为将来评估依据，不是当前待执行任务。

**现阶段以 ImageGen 直出寻找与制作怪物母版；用统一导出和独立动态标记控制尺寸与阵营。暂不把全怪物库迁移为 3D。** Blender 可以先作为小规模对照路线，适用于需要严格几何一致性、同体型多变体、多视角或动画的资产。

| 问题 | 2D 直出 | 建模后渲染 |
| --- | --- | --- |
| 找造型、手绘细节 | 可快速探索，参考图引导身份与材质 | 先要建立模型和材质；适合已有明确造型 |
| 相机、光照、盘径 | 提示词不能保证像素级一致，需检查和归一化 | 固定相机／灯光／模型尺度可复现 |
| 精确改一个部件 | 编辑可能连带改变其他部分 | 有独立几何或材质时可定点改动 |
| 多姿态与同体型变体 | 多图的一致性需要持续验收 | 可复用模型；姿态仍需调整或绑定 |
| 当前只显示一张小图 | 工作集中于玩家实际看到的画面 | 大量模型细节可能不体现在小尺寸成品上 |
| 主要风险 | 比例漂移、边界与 alpha、不同批次的风格变化 | 建模质量、过多细节、材质与造型不适合小尺寸 |

“AI 接入 Blender”解决操作途径，不自动解决有机生物的造型。规则圆盘、箱子、墙件容易参数化；狼的肩背、熊的体积、巨魔的脸和手仍需逐个审查。3D 既可以写实也可以风格化，不能把“3D”当作艺术统一的充分条件。

本轮已经观察到直出的具体成本：狼、熊和捕蝇草首图的主体在盘沿附近或越过盘沿，分别进行了定向返修。提示词中的盘径比例也没有严格实现，需统一工程导出。这支持测试更稳定的几何模板；但没有证明给每种怪物建完整 3D 模型一定划算。

推荐下一次对照取同一只狼，使用相同目标尺寸、同一棋盘和光线规范：比较 64px 识别度、五官与轮廓、统一视角、修改一个局部所需步骤、返修次数。若优势只在底盘，把底盘独立标准化即可；若模型复用和主体稳定性也明显获益，再扩展同族 3D 样本。尚未执行这次 Blender 对照。
