## 实现约束与取舍

1. **整体轻抬要核对坐标，而非只替换变量。** callback 的 `x,y` 包含起伏，`tlx,tly` 使用另一参考；主体存在 5% 内缩，big/small/old 后备路径、说话气泡、头像与地图回调不能直接混用。验收以可见圆盘和环心的相对位置为准。继续保留 overlay 单次绘制。
2. **固定朝向是候选默认。** 静态棋子烘焙了左上光源，原生镜像会翻转光照。抑制棋子显示镜像时仍保存原生朝向状态，使切回原图／外部替换正确；先比较“固定”与“原生跟随”，不把原生当前行为写成用户审美决定。
3. **不单独放大血环／护盾作为传送入座。** 原建议主体不缩、状态层 1.15→1.0 会分离刚体，也可能读成护盾变化。选择独立的中性到达短标记，或无新效果；标记不能像另一枚单位。
4. **可见性是硬约束。** 残留擦痕、传送原位标记须来自玩家实际观察到的事件，并在每次绘制时按当前视野／感知与显示准入裁剪；探索过的格子不是充分条件。主代理给评审的补充提示曾把 `seens` 说成探索记录，此处明确纠正：`map.seens` 是当前视野，记忆是 `remembers`／`has_seens`；已核对原生 `Map:cleanFOV`。仅视野仍不足以处理潜行、隐身、感知或 ESP，需要原生对单位的可见性判定。不要因一个单位随后可见而补画它此前隐藏的轨迹。改变控制者、离开区域、回退原图时清理瞬态数据。
5. **保留规则与响应。** 不等待动画、不锁输入、不改能量、逻辑位置、AI、攻击次数或技能回调。受击、击退、死亡、传送及新动作可中断旧显示；无位移时不画擦痕。未知显示和 shader aura 继续原生回退。
6. **近战挂钩须确认实际攻击阶段。** 本轮有限检索在原生 Combat:attackTarget 及 Actor 常规路径未见攻击 twitch，不推导所有技能均无动画。恐惧／取消、未命中、反击、附加攻击、远程 attackTarget 调用、Rush 末端须分别定义；不能只在入口无条件前冲。
7. **关键帧参数不等于严格毫秒保证。** 当前 C 路径线性；更换缓动需要另外的引擎或显示路径工作，不是理论上不可能。参考 100／133／267／300ms 是理想 30 归一化关键帧每秒换算，低 FPS 可能看不到中间帧。审查寻路的 180ms 是夹具调度间隔，不是原生固定节奏。
8. **先控制选项数量。** 沿用原生 smooth/twitch；样板阶段用测试开关比较朝向／单棋子滑行，验证后决定最终设置。不立即追加五个默认启用的独立动效选项。减少动态应可关闭额外前冲和提示，但不静默改写用户原生设置。

复核建议“确认命中才前冲”；主代理暂不将命中作为视觉触发的必要条件。实际挥击但未命中也可能需要动作反馈，应在近战样板中区分“已执行攻击”与“被取消”，再决定如何表达，不让前冲变成隐性的命中提示。

## 分轮执行与验收

1. **下一轮 A：整体轻抬和朝向对照。** 主体、血环、盾、角徽一起运动；原生模式可回退。测普通／斜行／快速反向、twitch开关、切换棋子模式和读档。48／64／96px 比较环心与盘心，停稳状态不跳变。无需 ImageGen。
2. **随后 B：单棋子特殊位移。** 从无主体副本开始，对照是否需要擦痕；分别测 Rush、击退、拉拽、Haste 普通步、带动画传送、连续输入、移动中死亡和模式回退。轨迹不泄露不可见格、不覆盖邻近单位的身份，低 FPS 不强求每次看到相同中间帧。
3. **随后 C：近战反馈和可选传送标记。** 只有前两轮值得继续后才做；多段／反击节流、非相邻调用、恐惧取消、未命中及隐身场景验收。不制作人物姿态帧，不新增施法或受伤全套动画。

每轮先做定向动作，再在 Board 与 Minimalist、48／64／96px、shader 开关、10／30／60 FPS 和可见／不可见起终点中抽查相关边界。使用 APNG、真实显示回调遥测及逻辑状态前后核对；只有实际执行的组合才能标记通过。自然混战和完整战役跨进程读档保持独立里程碑。
