# ToME 棋子外测包安装说明（棋子 0.6.6 / Board HUD 0.2.6）

适用：**Tales of Maj'Eyal 1.7.6** 的正常游戏。这个外层 ZIP 内有主插件 `tome-checker-revised.teaa`、可选的独立界面插件 `tome-board-hud.teaa`、本说明和 `SHA256SUMS`。本地验证使用的是 1.7.6；其他游戏版本及系统尚未验证。

1. 关闭游戏，解压**外层 ZIP**。如需核对下载文件，解压目录中的 `SHA256SUMS` 列出了两个 `.teaa` 和本说明的 SHA-256。
2. 找到游戏安装目录下的 `game/addons/`。把 `tome-checker-revised.teaa` 放进去；如想使用 Board 界面，再把 `tome-board-hud.teaa` 放进去。**不要解压 `.teaa` 文件**。若目录中已有这两个插件的旧版 `.teaa` 或同名解压目录，先移走旧版，避免游戏同时读到重复版本。
3. 启动游戏，在主菜单的插件列表确认主插件已启用。建议用**新测试角色**进入普通游戏，并在创建角色时确认启用了主插件；已有角色的插件关联和存档兼容性未作为本次外测结论。

主插件默认开启已覆盖生物的棋子，地形默认 **Native（原生）**。在游戏内打开 **Game Options → Token colors**，可切换 **Creature tokens**，用 **Board terrain** 循环选择 **Native / Blockout / Refined**。想看目前覆盖的地形，请选 **Refined**。棋子与地形选项彼此独立。主插件覆盖的是已经核准的 **37 种怪物身份**；未覆盖或不支持的外观继续使用原版画面。正常玩家角色的主体仍为原版。当前地形覆盖集中在非洪水版 Trollmire 及两种 Kor’Pul 布局中的部分格子、门和出口；其他地形按原版显示。这不是全游戏美术替换。

在 **Token colors → Token facing** 可选 **Fixed**（默认，棋子画面及绘制的光照方向固定）或 **Follow movement**（沿用原生移动和攻击时的水平翻转）。此选项只影响已覆盖的生物棋子；其他外观保持原生朝向。切换后立即生效并保存。平滑移动和原生起伏仍由游戏本身的选项控制。反馈移动表现时，请写明所选模式及当时的操作。

0.6.5 起让棋子、生命环、护盾和等级角标随原生起伏一起移动；没有新增走路帧。冲锋等动作仍保留原生主体残影，但不再复制多套状态环。单棋子疾滑、近战前探和传送新提示属于后续计划，本包尚未包含。

0.6.6 修正了图片在压缩插件中的读取兼容性，解决精修地形在正式安装后可能变黑的问题。素材和玩法不变；请用本次完整包替换旧版本。

`tome-board-hud.teaa` 是可选的独立插件，本包为 **0.2.6**。创建、初始加点及开场说明期间不显示角色栏、快捷栏和日志／聊天，进入游戏后自动恢复。启用后，在 **Game Options → UI → HUD Style** 中选择 **Board**，然后重启游戏使界面切换生效；不选择 Board 也可单独测试主插件。

**Game Options → Board HUD** 集中提供快捷栏行数、图标大小、最小地图高度、右栏宽度、聊天可见性、战斗日志字号、日志／聊天分区和地图形状；不再在 Game Menu 中逐项列出。Board 下修改立即生效并保存，其他 HUD 下修改只保存 Board 偏好。旧配置继续有效，右栏宽度可选 Automatic 恢复自适应。测试时请按正常游戏操作，无需调试命令、作弊模式或专用存档。

反馈时请附游戏版本、是否启用 Board、Token colors 的三个选项、角色和区域、出现问题前的操作，以及能够说明问题的截图或日志。若出现移动视觉问题，注明普通移动、击退、冲刺还是传送，以及是否只在移动过程中出现。
