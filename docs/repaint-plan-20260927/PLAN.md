# 常见怪物棋子与地形重绘方案

2026-09-27。审阅基线：棋子0.5.2，提交 `c59c21a`；Board HUD0.2.3。本文是主代理实际看图、核对本地ToME1.7.6源码后制定的方案，不冒充新的Opus评审，也不代表外部玩家测试。

**建议继续现有棋子路线，以“怪物家族＋地形套件＋一个可操作场景”组织下一阶段。下一个最小样板为3类骷髅、灰霉菌及6项石质地形母版，放进Kor'Pul遗迹验证。** 现有25款保留；先扩大新的战术类别，再处理少量暗体返修和森林规则缺口。

**变体修订：低级主线地城按DEFAULT与替代布局成对规划。** 完整[双变体方案](VARIANTS.md)与[20行覆盖矩阵](zone-variants.csv)优先于原M1–M5的顺序：Kor'Pul盗贼前移，三档冰元素、变体首领、恐魔、火系生物及附属房间怪群均已补入。首组4怪＋6地形是技术样板，不等于完成一个区域。

## 2. “常见”的范围和排序依据

近期范围为基础战役的六个1–7级起步区域：Trollmire、Kor'Pul、Norgos、Heart of the Gloom、Scintillating Caves、Rhaloren Camp；再扩展到7–16级的Old Forest、Maze、Sandworm Lair、Daikara。十区的两种布局共20条验收记录；同一区域两版的怪物／首领／地形同步进入计划，不再把替代布局当作默认版完成后的可选追加。不宣称这十区已经全部覆盖。

`tools/audit_repaint_sources.py`扫描89份基础区域定义及直接NPC脚本引用。直接复用较多的家族包括vermin16区、rodent13区、skeleton12区、snake11区；molds6区、plant6区。骨巨人13区、兽人12区也值得做，但多服务于后续战役阶段，暂排在起步场景之后。

**这些数字是包含条件分支的源码复用数，包含少数测试／城镇／特殊区域，不是刷怪频率或遭遇概率。** `all.lua`在40区被加载，此次没有递归展开；实际生成还受布局、区域过滤、等级、rarity、召唤和事件影响。现有25/57覆盖表也只是限定的九个森林／水域家族及固定独特怪样本，不能叫Trollmire覆盖率。

生产前每批先做原生解析清单：记录最终name、type/subtype、image、层叠显示、基础等级、来源、是否可自然生成；分别与对应区域两种布局的有效候选比对。区分普通怪、固定首领、条件房间及护卫／召唤；房间的等级偏移与地区降级回调必须进入解析。每完成一个可游玩片段，再采样多个未摆位的固定种子，记录实际遭遇和回退原因，用这些记录调整后续优先级。

## 4. 地形图案的视觉规则

地面是平面印刷棋盘，墙树是有厚度的构件，角色是圆底棋子，物品沿用现有独立托框。霉菌、毒藤、晶体即使不能走动，仍有演员圆盘和状态环；装饰蘑菇、花点、晶体岩石没有演员圆盘，二者不得混用形状。

| 语义 | 表现 | 不应暗示的规则 |
| --- | --- | --- |
| 普通地面／道路／花地 | 同一格面高度和格线，靠印刷材质及温和明度区分；花为零散小点。 | 道路没有凭空的速度／防御加成；花点不能看成障碍。 |
| 挡移动且挡视线 | 格内完整树或石墙上表面，边缘有厚度与短阴影。 | 造型不覆盖邻格棋子，不把图像高度等同于碰撞高度。 |
| 厚密树／硬墙／封门 | 更密闭的宽体轮廓、加固构造；类别稳定。 | 不能只凭同名“wall”或同一个原图判断可挖／可穿／可感知。确切例外仍以原生提示为准。 |
| 只挡移动、允许视线／投射物通过的构件 | 低矮炖锅、矮件，仍有明确落地点。 | 不画成高墙或伪装成可拾取物。 |
| 深水／无空气惩罚的沼泽水 | 深水暗大面、深度线；沼泽水较浅宽波纹、露出底色。 | 两者都可能可走。不能把水岸画成不可跨越的实体墙，也不按蓝色直接假定伤害。 |
| 开／关／封印门 | 同一门框；闭合门扇、敞开通道、封印构造对应状态。 | 开门是原生动作；不因显示变化改回合消耗或允许瞬间穿过。 |
| 上下楼、离区、特殊通路 | 可辨认的上／下台阶及独立世界地图符号，保持可站立格。 | 单个向上箭头不能表示所有出口。 |

地形规则读取最终Grid属性和受支持的来源，不仅查文件名。Daikara会移除所加载岩浆的 `on_stand`，这是反例：同图不等于同危险。普通门与巨石门通过原生 `block_move` 打开，不能只看 `does_block_move` 判成通路。

G0＋G1共18张地形母版。与M1的8款及最多2款暗体定向返修合计26–28项合格绘画结果，分轮完成；这不等于26–28次生成调用。上一轮8款使用11次ImageGen，只能作为现有家族的生产记录，不能用于保证骷髅手部、弓弦、门轴也有同样通过率。

以上26–28项仍是公共起始套件预算，**不是双变体交付总预算**。变体先新增坍塌迷宫裂隙1项及火山材料2项；梦境材质、房间特殊格等按各阶段Grid清单另核定，详见 `VARIANTS.md`。上下层及特殊出口不能仅复用同一个箭头。

地形应由ImageGen提供材质／构件母版，工程层完成固定格边、邻接蒙版、棋盘明暗和统一短阴影。避免让模型独立画一整套边缘后靠肉眼拼接。树木转透明母版需直接生成／编辑，不用程序抠掉草底或补画树干。带烘焙光影的构件不能随意旋转后假装光向仍一致。

连接验收至少覆盖16种四向邻接、孤格、直线、凹凸角、T口、十字、对角接触、单格窄道和不同材质交界；对角内角需要额外处理，不能认为16张已经解决全部情况。道路保持完整格位，任何装饰边只占本格，不能补出规则不存在的半格道路。

### 当前地形包的整理需求

本轮实数检查：`data/gfx/refined`共1682张PNG，当前选择器能构造的精修路径为78张；其余1604张不被这个选择器选中，其中1536张是旧 `path*`／`route*` 连续道路变体。其余文件合计约46.42MiB，指解压后的文件体积，不是压缩包节省量或显存量。

下一轮应把母版、构建器和生成清单收进插件仓库，以运行依赖白名单打包；历史试验保留在Git／证据中。**不要把1682张误算为1682项重绘，也不要仅凭本次静态集合直接删除历史文件。** 清理后需验证冷启动、地形三模式和实际路径命中，再报告压缩包变化。

## 6. 开始画下一批前的工程准备

1. **先做原生解析与精确白名单。** 新的3类骷髅及霉菌分别记录原生最终图像，不推测无显式image的命名路径。固定身份母版允许抽象服装和武器类别，不改变装备数据。普通高图支持须提前到P3 Norgos的三档shivgoroth之前；特殊shader、换体和叠层仍逐项验证，不一次放宽所有限制。
2. **扩充地形分类及局部刷新。** 受支持区域／Grid来源和通行、视线、感知、危险、交互分别记录；在开关门、挖掘和地形替换后刷新本格及必要邻域。避免每帧遍历全图；保留外部display及未支持Grid的回退。记忆区保持最后所见，不借贴图更新泄露未见区域的变化。

## 7. 下一轮可直接执行的最小样板

**制作范围：4款怪物＋6项地形母版。** 怪物为前述三类骷髅、灰霉菌；地形为石地板A/B、普通墙、硬墙、闭门、开门。对应M1第一组和G1第一组，不以临时占位图冒充最终结果。

先在独立离线夹具中固定一处Kor'Pul DEFAULT走廊，具有房间、转角、单格门口、可挖墙及一块普通地面装饰。使用真实原生定义，摆位只用于固定对照；保留另一份不摆位的种子作为实际生成样本，同时登记HIDEOUT的后续成对样本。原版／棋盘同布局同坐标同回合对照，Board与原生Minimalist至少各一组；不同布局不假设同seed会生成相同坐标。HUD源码无需参与本轮美术改造。

验收：

- 48px能分出近战骨架、弓手、法师和霉菌，64px能分出各具体身份；96px检查手、武器、骨架缺损是否符合原设定。
- 显示圈和遮住圈各看一次，同族识别不能靠等级徽章。灰度下关键轮廓保留；红／绿／蓝阵营与珍珠白护盾叠加不抹去主体特征。
- 地面装饰与可攻击霉菌明确区分。图上的闭门、开门、墙及地板可判读；鼠标实际点击、FOV和路径结果与原版一致。
- 真正开门、再关门、挖墙，检查当前格和邻接边缘立即更新；离开视线后的记忆状态仍遵循原生行为。未支持特殊门保持原图。
- 1920×1080和1366×768、48／64／96px，shader开关各有必要代表样本；至少一段移动、受击及施法录屏，不仅静态摆位。
- 记录通过的身份数／有效候选数、回退原因、母版尝试数、返修原因和实际接入工时。每轮验证后独立commit，截图带清单与hash。

第一组通过后先将原M4的四种盗贼前移，接着分小批补The Shade／The Possessed、M1剩余四款与G1其余四项，核对两版房间候选。只有DEFAULT／HIDEOUT各自的已支持和回退项都已记录，才报告Kor'Pul阶段结果。后续按P2–P10逐区成对推进；G0补全和暗体返修分别成轮，不在失败的门／墙协议上继续堆素材。美术与接入可由不同内置子代理并行，实机进程和最终提交由主代理统一操作。
